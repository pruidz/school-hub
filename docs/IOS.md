# Mac-ზე გადასვლა და iPhone-ის აპლიკაცია

ეს ფაილი იმისთვისაა, რომ Mac-თან რომ მიხვიდე, პირდაპირ დაიწყო — ძებნა არ დაგჭირდეს.

**მნიშვნელოვანი:** დღეს არსებული ვებ-აპლიკაცია სრულად მუშაობს iPhone-ზე მთავარ ეკრანზე
დამატებით, **შეტყობინებების ჩათვლით**. ეს ფაილი იმისთვისაა, თუ ამაზე მეტი მოგინდა —
App Store, ხატულაზე ციფრი, უფრო სწრაფი გაშვება.

---

## ნაწილი 1 — პროექტის გადატანა Mac-ზე (~20 წუთი)

### 1.1 რა უნდა დააყენო

გახსენი **Terminal** (Spotlight → „Terminal") და გაუშვი სათითაოდ:

```bash
xcode-select --install
```
(დეველოპერის ბაზისური ხელსაწყოები. თუ უკვე დაყენებულია, ასე გეტყვის.)

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
(Homebrew — პროგრამების მმართველი. მიჰყევი კითხვებს.)

```bash
brew install node git gh
```

შემოწმება:
```bash
node -v && git --version && gh --version
```

### 1.2 პროექტის ჩამოტვირთვა

```bash
gh auth login
```
აირჩიე: **GitHub.com** → **HTTPS** → **Yes** → **Login with a web browser** →
კოდს დაგანახებს → `Enter` → ბრაუზერში ჩასვი → **Authorize**

```bash
cd ~
git clone https://github.com/pruidz/school-hub.git
cd school-hub
npm install
```

### 1.3 გასაღებები — ხელით შეყვანა არ დაგჭირდება

```bash
npx vercel login
npx vercel link --yes --project school-hub
npx vercel env pull .env.local
```

ეს ჩამოტვირთავს **ყველა ცვლადს პირდაპირ Vercel-იდან** — Supabase-ის გასაღებებს,
`CHILD_AUTH_SECRET`-ს, VAPID-ს. არაფრის კოპირება არ გჭირდება.

### 1.4 შემოწმება

```bash
npm run doctor     # უნდა იყოს ყველგან მწვანე ✓
npm run test:db    # 257 ტესტი
npm run dev        # http://localhost:3000
```

**თუ სამივე გავიდა — Mac მზადაა და შეგვიძლია აპლიკაციაზე გადავიდეთ.**

## ნაწილი 2 — iPhone-ის აპლიკაცია (როცა გადაწყვეტ)

### 2.1 რა ჯდება

| | |
|---|---|
| Apple Developer Program | **$99 წელიწადში** |
| Mac + Xcode | გაქვს |
| დრო პირველ აწყობამდე | ~ერთი დღე |
| ვებ-კოდის გადაწერა | **არაფერი** |

### 2.2 რას ვიყენებთ — Capacitor

Capacitor იღებს **არსებულ საიტს უცვლელად** და ნამდვილ iOS აპლიკაციაში ათავსებს.
ერთი კოდი რჩება: იგივე რაც ვებზე მუშაობს, iPhone-ზეც იმუშავებს.

**რას ვიგებთ ვებ-ვერსიასთან შედარებით:**
- ნამდვილი push — Safari-ს შეზღუდვების გარეშე, გამოწერა არ ქრება
- ხატულაზე წაუკითხავების ციფრი
- აპლიკაცია მეხსიერებას არ კარგავს (ბავშვს PIN აღარ სთხოვს)
- ნამდვილი კამერა და დიქტოფონი
- App Store ან TestFlight

**რას ვერ ვიგებთ:** აპლიკაცია მაინც ვებ-გვერდია შიგნიდან. თუ ოდესმე მაქსიმალური
სისწრაფე მოგინდა, ეს უკვე სხვა საუბარია — მაგრამ ამ პროდუქტისთვის საჭირო არ არის.

### 2.3 ნაბიჯები (ერთად გავაკეთებთ)

1. Apple Developer ანგარიში — **შენ** ქმნი, $99 (Apple ID + გადახდა ჩემთვის დახურულია)
2. `npm i @capacitor/core @capacitor/cli @capacitor/ios` და `npx cap init`
3. აპლიკაციის კონფიგურაცია: ის ჩვენს **ცოცხალ მისამართს** ტვირთავს, ანუ ყოველი
   განახლება ავტომატურად მიდის — App Store-ში ხელახლა გატარება არ სჭირდება
4. `npx cap add ios` → `npx cap open ios` → Xcode
5. ხატულები და გაშვების ეკრანები — უკვე გვაქვს, გადმოვიტანთ
6. Push — APNs სერტიფიკატი Apple-ის პანელში, მერე კოდში
7. **TestFlight** — თავიდან აქ. საკუთარ ტელეფონებზე დასაყენებლად App Store-ის განხილვა
   საჭირო არ არის; ბმულით ეყენება. App Store მხოლოდ მაშინ, თუ სხვებისთვისაც გინდა.

### 2.4 რა უნდა იცოდე წინასწარ

- **$99 ყოველწლიურია.** თუ არ გაანახლებ, აპლიკაცია ტელეფონებიდან ქრება.
- **TestFlight-ის ვერსია 90 დღეში იწურება** — ყოველ სამ თვეში ხელახლა უნდა აიტვირთოს.
  App Store-ის ვერსია არ იწურება, მაგრამ Apple-ის განხილვას საჭიროებს (რამდენიმე დღე).
- **ბავშვების აპლიკაციებს Apple უფრო მკაცრად ამოწმებს.** ჩვენი შემთხვევა მარტივია
  (ოჯახური, რეკლამის გარეშე, მონაცემებს არ ყიდის), მაგრამ კონფიდენციალურობის პოლიტიკა
  დაგვჭირდება — მე დავწერ.

## რა გავაკეთოთ Mac-თან

დამიწერე **„Mac-ზე ვარ"** და:
1. გავივლით ნაწილ 1-ს ერთად — თუ რამე გაფუჭდა, მაშინვე გავასწორებ
2. თუ $99-ს გადაწყვეტ, ნაწილ 2-საც გავივლით

**თუ არ გადაწყვეტ — არაფერი გეშველება.** დღევანდელი ვერსია iPhone-ზე მთავარი ეკრანიდან
მუშაობს და შეტყობინებებსაც იღებს. ნაწილი 2 გაუმჯობესებაა, არა აუცილებლობა.
