# პირველი გაშვების შემოწმება

გაიარე ეს სია მას შემდეგ, რაც [SETUP.md](SETUP.md)-ის 1–5 ნაბიჯს შეასრულებ და **სანამ**
ნამდვილ მონაცემებს შეიყვან.

მიგრაციები გაუშვი **ზუსტად ამ თანმიმდევრობით**: `0001 → 0002 → 0003 → 0004 → 0005 →
0006 → 0007`. `0007` აუცილებელია — ის ხურავს უსაფრთხოების ხვრელს, რომელიც `0004`-ს
რჩება. თუ გამოტოვებ, ინტერფეისში ვერაფერს შეამჩნევ, მაგრამ ცნობისმოყვარე ბავშვი
მთელ ოჯახის მონაცემს დაეუფლება.

- [ ] რეგისტრაცია მშობლის ანგარიშით, შესვლა, გამოსვლა, შესვლა ხელახლა
- [ ] ერთი ბავშვის დამატება → მოწვევის კოდის გენერაცია
- [ ] კოდით `/join`-ზე შესვლა **მეორე ბრაუზერში ან ტელეფონში**, PIN-ის არჩევა
- [ ] გამოსვლა და ხელახლა შესვლა PIN-ით
- [ ] საგნების დამატება, კვირეული ცხრილის შევსება
- [ ] ბავშვის `/kid/today` — დღევანდელი გაკვეთილები ცხრილიდან გამოჩნდა?
- [ ] ბავშვმა ჩაწერა „რა გავიარეთ" და ატვირთა წიგნის ფოტო
- [ ] მშობელმა შექმნა დავალება
- [ ] ბავშვმა ატვირთა ამოხსნის ფოტო, შეავსო თვითშეფასება და ჩააბარა
- [ ] მშობელს `/parent/inbox`-ში გამოუჩნდა
- [ ] შემოწმების ეკრანზე ორივე ფოტო ჩანს და **იდიდება**
- [ ] „გადასაკეთებელი" კომენტარით → ბავშვს ზემოთ, თვალშისაცემად უჩანს
- [ ] ხელახლა ჩაბარება → „დადასტურება"
- [ ] დავალებაზე ჩატი — ორივე მხრიდან

## ბ. უსაფრთხოების მიღება (აუცილებელი)

დაამატე **ორი** ბავშვი, ორივეს გაუკეთე ლოგინი. ორივეს ჰქონდეს დავალებები.
ყველა შემოწმება ხდება **პირველი ბავშვის** სესიით. ყველგან პასუხი უნდა იყოს „არა".

- [ ] **1. მეორე ბავშვის მონაცემი ჩანს?** პირველი ბავშვის ლოგინით სცადე მეორის
      დავალების მისამართის პირდაპირ გახსნა (`/kid/assignments/<მეორის id>`) → უნდა
      დაბლოკოს
- [ ] **2. საკუთარი თავის მშობლად გამოცხადება.** ბავშვის სესიით, ბრაუზერის კონსოლში:
      ```js
      const { createClient } = await import('@supabase/supabase-js');
      ```
      მარტივი გზა: გახსენი Network ჩანართი, იპოვე PostgREST-ის მოთხოვნა და გაიმეორე
      `profiles` ცხრილზე `role: 'parent'`-ით → უნდა დაბრუნდეს შეცდომა
- [ ] **3. საკუთარი დავალების დადასტურება.** ბავშვი ვერ უნდა ახერხებდეს სტატუსის
      `approved`-ზე გადაყვანას
- [ ] **4. ვადის შეცვლა.** ბავშვი ვერ უნდა ცვლიდეს დავალების ვადას ან ტექსტს
- [ ] **5. PIN-ის ბლოკის მოხსნა.** განზრახ შეიყვანე 5 არასწორი PIN → უნდა დაიბლოკოს
      15 წუთით. ბავშვმა ვერ უნდა მოხსნას; **მშობელმა** — `/parent/children`-იდან —
      უნდა შეძლოს
- [ ] **6. სხვისი ფოტოს ნახვა.** დააკოპირე მეორე ბავშვის ფოტოს მისამართი და გახსენი
      პირველი ბავშვის სესიით → უნდა უარყოს
- [ ] **7. მოწვევის კოდის ხელახლა გამოყენება.** ერთხელ გამოყენებული კოდი მეორედ არ
      უნდა მუშაობდეს

თუ რომელიმე გამოვიდა — **გამაჩერე და მითხარი**. ნამდვილ მონაცემებს ამის გარეშე ნუ
შეიყვან.
